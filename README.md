📚 Librar — Library Management System
A modern desktop library management system built with C# and Windows Forms to organize, track, and manage books, members, and borrowing activity efficiently.
---
🚀 Features
Book Management: Add, edit, catalog, and remove books with ease.
Search & Filter: Find books quickly by title, author, category, or status.
Borrowing & Return System: Track issued books, due dates, overdue records, and return statuses.
Member Records: Maintain member profiles, contact information, and borrowing history.
Modern UI Experience: Clean, responsive Windows Forms interface powered by Guna.UI2 for intuitive navigation.
---
🛠️ Tech Stack
Layer	Technology
Language & UI	C# / Windows Forms
Framework	.NET Framework 4.8

📦 Getting Started
Prerequisites
Ensure you have the following installed on your machine:
Visual Studio 2019 or later with the .NET desktop development workload.
.NET Framework 4.8 SDK
Windows 10 or Windows 11
Setup & Run
Clone the repository:
```bash
   git clone https://github.com/DevHatemAlDouh/librar.git
   cd librar
   ```
Open the Project:
Double-click `Librar.sln` to open the solution in Visual Studio.
Restore Packages:
NuGet will automatically restore missing dependencies (such as `Guna.UI2`). If not, right-click the solution in Visual Studio and select Restore NuGet Packages.
Build & Run:
Press `F5` or click Start in Visual Studio to build and execute the application.
